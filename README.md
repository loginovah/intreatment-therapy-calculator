# Калькулятор длительности терапии InTreatment

Интерактивный калькулятор даёт предварительный ориентир по количеству встреч,
календарной длительности терапии и возможному бюджету. Расчёт не является
диагнозом или назначением курса терапии.

## Публичная версия

[Открыть калькулятор](https://loginovah.github.io/intreatment-therapy-calculator/)

## Локальный запуск

Требуется Node.js 22 или новее.

```bash
npm ci
npm run build:pages
```

Статическая сборка появится в каталоге `out`.

## Публикация

GitHub Actions автоматически собирает и публикует сайт в GitHub Pages после
каждого обновления ветки `main`.
